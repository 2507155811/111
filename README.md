若聊天内置浏览器无法下载，请复制链接到系统浏览器打开。

淘宝、京东浏览任务的本地辅助应用，面向小米 17 Pro Max / HyperOS。安卓 8.0+，无网络权限，无云服务，无广告。尚未进行真实手机或当前双11活动的端到端验证。

## 使用

1. 安装 `dist/browse-helper-0.1.0.apk`。这是本地测试签名，不是商店发布版。
2. 打开应用，阅读说明，在系统无障碍设置中开启“浏览小助手”。仅在你信任源码与安装包时授权。
3. 勾选应用中的授权说明，选择淘宝或京东。手动打开相应活动的任务列表。
4. 点击悬浮条“开始”。拖动悬浮条文字区域可移动，避免遮挡任务按钮。点击“停止”暂停，“关闭”结束并移除控制条。
5. 软件识别明确的浏览任务，打开后等待新出现的完成提示，返回后核对同一任务已完成。两次确认成功才计数并学习。每轮最多20项、20分钟，每项最多等90秒。

## 学习与本地指令

确认成功后保存平台、应用版本与任务特征的 SHA-256 哈希。不会保存截图、完整页面或账户信息。下次可复用识别；应用版本改变后旧特征不用于“仅已学”模式。学习记录可清除，不代表平台承诺任务永久可用。

本地指令助手是受限的离线规则式意图解析器，不含神经网络或大语言模型。支持：

- `淘宝浏览3个任务`
- `京东浏览5分钟`
- `淘宝只做已学任务`
- `京东只做已学任务浏览3个任务`
- `停止`
- `清除学习记录`（二次确认）

开始指令仍需用户打开任务列表并点击悬浮条开始。无法处理的指令会拒绝，不会推测并执行。此版本不支持语音或开放式对话。

## 边界

- 仅支持无障碍树能读取文字的界面，不含 OCR。纯图片、Canvas、部分网页无法识别时停止。
- 只处理当前可见范围；没有任务时停止，用户手动滚动后再开始。没有坐标盲点、自动破解验证或自动滚屏。
- 登录、验证码、支付等敏感界面会暂停。不会处理下单、加购、收藏、关注、分享、邀请、开会员等任务。
- 自动操作可能触发平台风控，任务奖励、页面兼容性和完成率无法保证。页面变化时需重新适配。
- 完成提示未出现、返回后状态不明确、控制条挡住按钮等情况都会暂停；不会把等待够时长当成完成。
- 系统可能中止后台服务；如有需要，在系统应用电池设置中检查后台运行限制，不应关闭系统安全保护。
- 关闭应用不会撤销无障碍授权；不用时可在系统设置中关闭服务。

## 构建与验证

Linux 环境，需要 Python 3、Java 21 运行时、keytool，以及官方 Android 构建工具所需系统库。运行：

```sh
bash tools/build.sh
```

引导脚本将 Android 36 平台、Android 35 构建工具和 Eclipse ECJ 3.40.0 编译器下载到 `/workspace/android-task-tools`。保留 TLS 和 SHA-1 官方分发校验；ECJ 校验来自 Maven Central 的对应校验文件。编译输出、测试签名密钥仅保存在 `build/`，请妥善保留密钥用于后续覆盖安装。测试口令是公开的，仅用于本地试用，不适合作为正式发布密钥。

构建执行既有纯 Java 规则测试、DEX 转换、打包、对齐和签名，检查 APK 签名、入口、SDK、资源和无网络权限。这些检查不等于真机运行验证。实际小米手机、无障碍授权、淘宝与京东活动流程仍需真机验证。
