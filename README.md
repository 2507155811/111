淘宝、京东浏览任务的本地辅助应用，面向小米 17 Pro Max / HyperOS。安卓 8.0+，无网络权限，无云服务，无广告。尚未进行真实手机或当前双11活动的端到端验证。

## 使用

1. 安装 `dist/browse-helper-0.6.0.apk`。这是本地测试签名，不是商店发布版。
2. 打开应用，阅读说明，在系统无障碍设置中开启“浏览小助手”。仅在你信任源码与安装包时授权。
3. 勾选应用中的授权说明，选择淘宝或京东。手动打开相应活动的任务列表。
4. 点击悬浮条“扫描确认”，核对浏览任务清单，勾选需要执行的条目并调整本轮次数，再确认执行。拖动悬浮条文字区域可移动，避免遮挡任务按钮。点击“停止”暂停，“关闭”结束并移除控制条。
5. 软件识别明确的浏览任务，打开后读取浏览时长；出现新完成提示或到达浏览时长并留出4秒余量后返回，核对同一任务的计数增加或已完成。返回后核对进度增加或明确的完成状态才计数并学习。每轮最多20项、20分钟，每项最多等90秒。重复任务会在进度增加后继续下一次，如 `(0/10)` 到 `(1/10)`；等待时间本身不计为成功。

## 学习与本地指令

确认成功后保存平台、应用版本与任务特征的 SHA-256 哈希。不会保存截图、完整页面或账户信息。下次可复用识别；应用版本改变后旧特征不用于“仅已学”模式。学习记录可清除，不代表平台承诺任务永久可用。

本地指令助手是受限的离线规则式意图解析器，不含神经网络或大语言模型。支持（基于实际页面文字，任务名称可变化）：

- `淘宝浏览3个任务`
- `京东浏览5分钟`
- `淘宝只做已学任务`
- `京东只做已学任务浏览3个任务`
- `停止`
- `清除学习记录`（二次确认）

开始指令仍需用户打开任务列表并扫描确认任务清单和数量。无法处理的指令会拒绝，不会推测并执行。此版本不支持语音或开放式对话。

## 边界

- 仅支持无障碍树能读取文字的界面，不含 OCR。纯图片、Canvas、部分网页无法识别时停止。
- 读取当前可见范围；完成可处理任务后，仅在确认的任务列表中最多向下滚动8次查找更多任务。无新页面或不支持滚动时停止，没有坐标盲点或自动破解验证。
- 登录、验证码、支付等敏感界面会暂停。不会处理下单、加购、收藏、关注、分享、邀请、开会员等任务。
- 自动操作可能触发平台风控，任务奖励、页面兼容性和完成率无法保证。页面变化时需重新适配。
- 没有可读浏览时长和完成提示、返回后进度不增加或完成状态不明确、控制条挡住按钮等情况都会暂停；不会把等待够时长当成完成。
- 系统可能中止后台服务；如有需要，在系统应用电池设置中检查后台运行限制，不应关闭系统安全保护。
- 关闭应用不会撤销无障碍授权；不用时可在系统设置中关闭服务。

## 构建与验证

Linux 环境，需要 Python 3、Java 21 运行时、keytool，以及官方 Android 构建工具所需系统库。运行：

```sh
bash tools/build.sh
```

引导脚本将 Android 36 平台、Android 35 构建工具和 Eclipse ECJ 3.40.0 编译器下载到 `/workspace/android-task-tools`。保留 TLS 和 SHA-1 官方分发校验；ECJ 校验来自 Maven Central 的对应校验文件。编译输出、测试签名密钥仅保存在 `build/`，请妥善保留密钥用于后续覆盖安装。测试口令是公开的，仅用于本地试用，不适合作为正式发布密钥。

构建执行既有纯 Java 规则测试、DEX 转换、打包、对齐和签名，检查 APK 签名、入口、SDK、资源和无网络权限。这些检查不等于真机运行验证。实际小米手机、无障碍授权、淘宝与京东活动流程仍需真机验证。

## 0.3.0 更新

收紧任务列表识别，防止浏览页上的“任务 / 去完成”浮层阻断返回计时。加入浏览页内最多6次轻滑（间隔至少3.5秒），先尝试无障碍滚动，再使用无障碍手势。仅在已确认进入浏览页后执行；不滑动支付、验证或其他应用。网页按钮动作失败时可点击实时识别的按钮区域，按钮报告点击成功但4秒后页面仍完全未变化时只补点一次。排除助手悬浮窗对活动窗口读取的干扰；返回后对两平台的明确任务入口执行重新打开，并在仍有倒计时的多层浏览页中最多返回3层。此版本增加手势能力，覆盖安装后需重新关闭并开启无障碍服务。仍需真机验证，不能保证活动页面全兼容。

## 0.4.0 更新

新增运行前任务清单与数量确认，支持勾选和次数滑杆。仅统计当前屏幕可见且有明确浏览要求的条目；显示任务种类、剩余次数和时长，没有进度标记时本轮最多1次。确认后重新读取页面，任务或进度变化则停止要求重新确认。执行中仅允许已勾选任务，在确认的剩余次数范围内重复，未知新任务不自动加入计划。非浏览以及混合加购、关注、预约、答题等操作一律排除。当前列表外的条目不在计数内，可取消、手动滚动再扫描；任务列表自动滚动不会授权未勾选任务。

## 0.5.0 更新

连续执行已确认清单：完成核对后自动切换，优先其他任务，再回到可重复条目。已经返回列表但未能确认进度的任务会标为跳过，不计成功，继续其他已勾选任务。无法安全返回、验证或敏感界面仍暂停。滑动改为仅在行说明或浏览页明确要求滑动时触发，普通停留任务不滑动。时长优先依据实时倒计时，倒计时卡住不判成功；没有倒计时时用初始时长加缓冲后返回核对。补充京东合并文字控件的任务识别，并显示扫描开始、结果和异常信息。仍需真机确认京东可读性及实际行为。

## 0.6.0 更新

补充向上划、滑一下、滚动页面等文字提示，并读取浏览页更深层可见节点和本应用的无障碍提示事件。纯箭头动画没有可读文字时，当前版本不能可靠自动识图判断；可以在任务浏览中点悬浮条“需滑动”，或在任务确认清单中勾选本项要求滑动。标记按平台、应用版本、任务特征的哈希存储，后续同一任务自动采用，不影响其他任务；确认清单中可取消该标记，“清除学习记录”也会清除滑动标记。没有文字要求且未标记的普通浏览任务只停留，不默认滑动。
